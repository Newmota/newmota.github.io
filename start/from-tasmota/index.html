    Switching From Tasmota¶

    This page moves an ESP32 device that runs Tasmota to Newmota. If your device runs something else, or you want a clean start, flash it over a cable as described in Install & Update Firmware and set it up with First Steps.

    Tasmota is a mature, widely used firmware, and Newmota is a young pre-alpha project that follows its commands and templates. Keep that in mind before you replace a working Tasmota device: choose one you can open and reflash over a cable if something goes wrong.

    Not tested end to end yet

    The update from Tasmota and the import of its settings are built into every supported Newmota ESP image, but a full trial on a device is still open. Expect rough edges and keep a cable at hand.

    Two ways to switch¶

    Over the air, from Tasmota's web page Over a cable
    Chips ESP32, S2, S3, C2, C3, C5, C6, P4 Every supported chip
    Wi-Fi and web password Taken over from Tasmota Set again
    Tasmota's filesystem Kept Replaced
    Tasmota's Safeboot Stays installed Replaced by Newmota's Safeboot
    Newmota's own update path (Upgrade 1) Not available until a factory flash Available

    Either way, templates, GPIO assignments, MQTT and all other settings are not taken over. Write them down first, as described in the next section.

    1. Note what you want to keep¶

    On the Tasmota console, run these and copy the answers to a text file:

    Command What it shows
    Template The device template: the pin layout of your plug, switch or bulb
    Module Whether the template is active (0 means the template is used)
    MqttHost, MqttPort, MqttUser, Topic The MQTT connection. The password is not shown; have it at hand
    DeviceName The name your smart home shows
    Timezone The time zone

    Newmota understands the same commands, the same template JSON and the same GPIO function numbers, so you can paste the answers back later. The Coming from Tasmota page lists where Newmota differs.

    2. Build the Newmota image¶

    Build an environment with the same chip and flash size as the device, as described in Build Your Firmware. Tasmota's Status 2 shows the chip and Status 4 the flash size.

    The image for the over-the-air path is in the build's ota/ folder:

    build/firmware/<environment>/<version>/ota/newmota-<environment>-<version>-ota.bin

    3a. Switch over the air¶

    1. Open the Tasmota web page and go to Firmware Upgrade.
    2. Under Use file upload, choose the -ota.bin file from step 2 and press Start upgrade. For a large file Tasmota shows Switching to safeboot partition and continues in its Safeboot; if the Safeboot page asks for the file again, choose the same file.
    3. The device restarts into Newmota. On the first start with default settings, Newmota reads the Wi-Fi networks, the preferred network and the web password from Tasmota's settings and joins your Wi-Fi.
    4. Find the device on your network as before and open it in the browser.

    What Newmota imports:

    • Both Wi-Fi networks (SSId1/Password1, SSId2/Password2) and the preferred one.
    • The web password, if it is 8 to 64 characters long. If it is not imported, the web interface stays open until you set one with WebPassword.

    The import reads the settings layout of Tasmota 15.5.0.2. Settings from another version, or settings that are damaged, are skipped, and the device starts its setup network newmota-XXXXXX instead, as described in First Steps. Tasmota's settings files stay where they are; Newmota does not change them.

    ESP32-H2, ESP32-C61 and ESP32-S31 are not supported by the import. ESP32-P4 stores the imported credentials, but its Newmota application has no Wi-Fi yet.

    3b. Switch over a cable¶

    Follow Install & Update Firmware: take a full backup with make backup first, then make flash, or use the Web Flasher. Then connect the device to Wi-Fi as described in First Steps.

    The backup keeps the whole flash, Tasmota included, so you can write it back later.

    4. Set the device up again¶

    Paste the values you noted in step 1 on the Newmota console, for example:

    Template {"NAME":"My Plug","GPIO":[...],"FLAG":0,"BASE":1}
Module 0
MqttHost 192.168.1.10
MqttUser mqttuser
MqttPassword <your password>
Topic myplug

    Then check the hardware with Power1 on or Dimmer 50. Details are in Setting Up Your Device Hardware and MQTT & Telemetry.

    After an over-the-air switch¶

    Tasmota's Safeboot stays on the device:

    • Restart 3, or Restart into Safeboot on the Firmware Update page, starts it. Its web page accepts a newer Newmota .bin or a Tasmota .bin, so you can go back to Tasmota the same way you came.
    • Tasmota's Safeboot keeps its own copy of the Wi-Fi settings. Wi-Fi changes you make in Newmota do not reach it, but its recovery access point stays available.
    • Upgrade 1 needs a Newmota Safeboot and reports Native update path unavailable on a switched device. A factory flash over a cable installs the Newmota Safeboot.
