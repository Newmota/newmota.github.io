    Web Flasher¶

    The Web Flasher writes a Newmota factory package from the browser, without a build environment. Every build places the package next to its manifest, for example build/firmware/cb2s-2m/<version>/newmota-cb2s-2m-<version>-factory.zip. Load it below, connect the device and press Connect and write. It needs a desktop Chrome, Edge or other Chromium browser (Web Serial, and WebUSB for the Pico).

    • It writes the same regions as make flash-only PACKAGE=… and refuses the same cases: a flash smaller than the package, a chip other than the package's, Beken modules without RF calibration where the layout keeps it, and ESP chips with secure boot, flash encryption or secure download mode.
    • Back up the whole flash before writing is on by default. The backup downloads before anything is written; Back up only reads it without writing. Keep backups private: they can contain Wi-Fi credentials and device keys. AmebaD has no backup, as with make.
    • The baud rate defaults to the upload speed of make flash. After a successful write the serial monitor opens at the console speed; reset the board if it does not start by itself.
    • A Raspberry Pi Pico is written over USB in BOOTSEL mode: choose the board, and a board running Newmota switches to BOOTSEL by itself (then press the button again and choose the RP2 Boot device); otherwise hold BOOTSEL while plugging it in.

    The flasher is not part of this build of the documentation. Build it with npm run build in flasher/.

    The flasher is free software under the GNU GPL 3.0 or later. Its components and the loaders it sends to a chip, with their licenses, are listed in its THIRD_PARTY.md.
